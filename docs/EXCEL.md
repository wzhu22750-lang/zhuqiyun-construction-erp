# Excel 导入与导出

Excel 功能使用真实后端接口和 MySQL，文件格式为 `.xlsx`。页面入口会根据账号权限显示，后端再次检查权限及项目范围。

## 导入档案

供应商管理、材料档案、项目管理、仓库管理页面右上角提供“导入 Excel”。

1. 点击“下载 Excel 模板”。在“导入数据”工作表第二行起填写，保留第一行表头；“填写说明”工作表列出规则。
2. 选择填写后的 `.xlsx`，点击“预览并逐行校验”。弹窗显示 Excel 原始行号、中文字段、通过行数和错误行数。
3. 所有行通过后，点击“确认导入 N 行”，再次确认后整批新增。导入成功会刷新列表。
4. 有错误时，先修改原文件，再重新选择和预览。任一行有误，整批都不会写入。已有编号和重复文件报错，不覆盖原档案。

| 导入类型 | 必填字段 | 其他说明 |
| --- | --- | --- |
| 供应商 | 编号、名称 | 状态可省略，默认 ACTIVE；评级默认 4.5；有效期用 yyyy-MM-dd |
| 材料 | 编号、名称、单位、分类 | 安全库存最多三位小数，参考单价最多四位小数；省略时为 0 |
| 项目 | 编号、名称、建设单位、承建单位、负责人登录名、合同金额、预算金额、开始日期、结束日期 | 负责人须启用且为项目经理或企业负责人；经理只能指定本人；进度和状态可省略 |
| 仓库 | 编号、名称 | 可填写仓库地址 |

每批最多 300 行、2MB。模板的编号、电话及负责人登录名列采用文本格式，填写时保留编号前导零。支持 Excel 日期单元格及 yyyy-MM-dd 文本日期；金额最多两位小数。拒绝公式、宏、外部链接和模板以外的数据列；解压后最多 20MB、200 个 ZIP 项。

材料与仓库导入仅建立档案，不生成库存、出入库流水或项目成本。采购交易及付款仍通过现有业务表单与审批流程登记。

## 导出列表

在对应页面点击“导出 Excel”，按当前搜索、状态、项目或仓库等已生效筛选导出，覆盖全部匹配记录，最多 5000 条。超过上限会提示缩小范围；导出范围始终受当前账号权限约束。

| 页面 / 页签 | 导出内容 |
| --- | --- |
| 项目、供应商、材料、仓库 | 对应档案列表 |
| 采购申请、询价与比价 | 当前申请列表；询价页沿用已审批 / 已下单的申请范围，附材料明细 |
| 采购订单 | 订单头、材料明细、验收 / 关闭 / 退货数量 |
| 合同 | 合同基本信息、关联项目 / 订单 / 供应商、金额及日期 |
| 成本费用 | 当前项目成本总览或费用登记明细 |
| 实时库存、出入库流水 | 当前库存或对应流水；无计价权限时移除计价列 |
| 入库单、领料与退料、退料记录 | 当前页签的单据；入库、领料附明细 |
| 库存盘点 | 盘点单和账面 / 实盘 / 差异数量；调整金额按权限输出 |
| 应付账款 | 应付、净实付、未付、退款与付款申请占用 |
| 付款申请、付款记录、供应商退款 | 当前页签和筛选对应的记录 |
| 应付账款页“导出累计对账” | 供应商当前累计余额；沿用应付列表搜索条件 |

下载文件名为中文业务名称及日期；模板文件名为“业务名称导入模板.xlsx”。数据表冻结首行并提供筛选，附“口径说明”工作表。金额、数量和比例为数值单元格，日期为 Excel 日期；超过 15 位有效数字的数值转为精确文本。电话、编号及公式外观的普通文字保持文本，不执行公式。

项目成本中的“合同额减已登记成本”与完工利润预测不同；对账为当前累计余额，不包含期间期初期末账。采购退货不会恢复原订单待履行量。

## 接口与验证

接口见 [API-CONTRACT.md](API-CONTRACT.md)。导入权限：供应商 / 材料 / 仓库需要 `master:write`；项目需要 `project:write`、`cost:read`、`contract:read`。导出复用相应列表的读取权限与项目范围；盘点额外要求 `stocktake:read` 和 `inventory:company`。

独立试用实例运行后，可以执行：

```sh
API_BASE=http://127.0.0.1:18092/api python3 scripts/test_excel.py
```

此脚本新增带 QA 标识的四类档案，不清理或覆盖既有数据；验证四种模板及导入、20 类导出、错误整批拒绝、重复拒绝、文本和电话保留、权限及项目范围。可将 `EXCEL_QA_DIR` 指向任务临时目录，保存浏览器复验用的合法 / 非法仓库文件与供应商导出样本。
