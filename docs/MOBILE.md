# 手机浏览器适配与验收

执行日期：2026-10-21。现有 Vue 网站支持手机浏览器打开，无需安装独立 App。

## 页面与交互

- 视口小于 768px 时使用抽屉导航，按角色过滤菜单，切页自动关闭；平板和桌面保留原有工作区。
- 业务列表在手机上按卡片展示，保留全部字段、状态、搜索、分页及权限动作，默认每页 5 条；桌面继续使用表格。
- 采购申请、报价、验收入库、领料的多行材料改为纵向填写；详情描述改为单列。
- 弹窗内容独立滚动，底部操作区保留在可视范围；输入控件、按钮和下拉选项扩大触控区域。
- 手机预算图使用横向条形图，金额单位和长名称适配；图表随容器尺寸更新。
- 供应商详情抽屉适配手机宽度，日期选择器和确认框限制在视口内；支持安全区和动态视口高度。

## 本地手机访问

默认部署仍只绑定本机。需要同一局域网的手机访问时，仅开放网页端：

```sh
UI_BIND_ADDRESS=0.0.0.0 UI_PORT=18081 API_PORT=18082 DB_PORT=13307 \
COMPOSE_PROJECT_NAME=zqy-acceptance ./scripts/start-compose.sh up -d --build --no-deps frontend
```

手机和电脑连接同一 Wi-Fi，通过 `http://电脑的局域网IP:18081` 打开。macOS 可用 `ipconfig getifaddr en0` 查询地址；网卡或 DHCP 地址变化时以实际结果为准。`UI_BIND_ADDRESS` 单独控制网页端绑定，不改变 API 和 MySQL 的本机绑定。手机浏览器通过同源 `/api` 访问后端。首次部署整个系统仍按 README 启动全部服务。
