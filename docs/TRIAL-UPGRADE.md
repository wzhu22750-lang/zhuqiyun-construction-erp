# 小企业本地试用增强交付

本轮基线为 db6850a（任务开始时与 origin/main 一致）。保持 Spring Boot + MySQL + Vue 3 模块化单体、中文界面与手机适配，不引入云服务、Redis、微服务或多租户。最终定位为可在本地试用的单公司业务系统，不是已完成财税总账或商业 SaaS。

## 已实现的业务

- 后端详情、聚合、bootstrap、看板、分页、追溯、导出与打印按模块权限过滤；经理仍只能查询本人负责项目。无权限金额不返回，无权限区块为空并携带 access 标志，见 [读取权限契约](READ-PERMISSIONS.md)。
- 原首页内嵌角色工作台，经理、采购、仓库、财务、负责人各突出 3–5 类实际任务。SQL 计算总数，展示最早等待的 5 项；全部入口进入同一业务页面。请求成功写操作、页面获得焦点、恢复可见及每 30 秒刷新。只有付款阶段 due_date 可以判定到期；等待天数不表示逾期。
- 申请、订单详情增加全链追溯：申请、审批、报价、授予、分次验收、采购退货、应付、付款申请记录、实付、退款、关闭/取消、补采，以及人工明确来源的项目领退料。时间线在 SQL 中分页，真实空状态；历史缺少操作人时明确显示未知，不编造历史。
- 合同计划使用可增删、排序、手机编辑的阶段表单；金额预览按整数分计算，最终以 BigDecimal 服务端校验为准。允许未分配合同余额，阶段日期可未约定。实际付款/退款须人工选择明确关联的订单记录，不能根据日期或金额猜测阶段。
- 库存模块新增盘点单，从草稿到独立审核生效。审批才调整库存，差异独立流水，不写项目成本。库存期间变化、旧版本和重复审批均由后端阻止。
- 主业务列表及本轮详情关联表使用服务端分页、关联筛选、搜索。基础资料选择器远程搜索；bootstrap 仅加载最初 100 项选择缓存。旧数组接口保留供原集成使用，主要头列表最多 200 项、详情样本最多 20/50 项，完整记录以 `/records` 和 `/trace` 为准，不以样本长度计算业务总量。
- 供应商、材料、项目、仓库支持 Excel 模板、逐行预览、整批新增导入；主要档案、采购、合同、成本、库存和财务列表共 20 类支持 Excel 导出；订单、入库、领料、对账有 A4 打印预览和浏览器打印。

## 采购与金额口径

订单原数量、原金额保留。待履行 = 原数量 − 累计验收 − 关闭数量；采购退货不会恢复待履行，补采须创建明确关联的新草稿重新审批。采购净订单额 = 原金额 − 关闭金额 − 采购退货金额。原入库不直接等于项目成本。

应付 = 原验收入库金额 − 采购退货冲减；净实付 = 原付款 − 实收退款。未付与待退款分别取差额的非负方向。申请占用仅计 PENDING / APPROVED，已驳回/撤回释放；可申请余额同时受未付、申请占用及关联合同限额约束。

`registered_cost_balance` 名称为“合同额减已登记成本”，需要合同及成本读取权限。它不是预计最终利润，不包含虚构完工成本预测。项目消耗材料成本 = ISSUE − ISSUE_RETURN；盘点差异不自动加入任何项目。

领料可选 `order_item_id` 明确采购来源，按同项目、同材料、同仓验收净来源数量校验，并保留到退料流水。计价仍采用仓库移动加权法，不把来源采购单价冒充领料成本。未指定来源的旧领料不会根据相同材料、项目猜测；被明确领用的来源须先项目退料恢复来源余量，才能向供应商退货。

## 合同付款计划

服务端限制阶段最多 100 行，金额最多 2 位小数且非负、ISO 日期合法、总额不大于合同额。保存携带 `expected_version`；并发旧版本拒绝。原始文本可识别时只读展示，不在 GET 中迁移；百分比、缺金额或不合法 JSON 无法自动还原时展示原文和原因，只有明确确认后才重建，原文进入 `contract_plan_history`。

计划保存需要 `contract:plan` + `contract:write` + `finance:read`；实际关联/取消需要合同读取及 `finance:read/write`。有过实际关联的阶段不能删除。取消关联只改变分配关系，保留原因与历史，不撤销真实付款。无法准确追踪实际付款的未关联订单合同仍可维护计划，但明确告知不支持实际分配。到期提醒表达“约定日期已到、尚需核对关联”，未关联不能直接断言未付。

## 盘点规则

草稿/驳回可由原申请人维护；待审可撤回。保存和提交不创建库存行。审核需要 `stocktake:approve`，且审核人与申请人不同；生效后禁止编辑，只能新建关联 `correction_of` 的纠正盘点。

新明细必须先读取账面快照，提交 `snapshot_revision`。审核检查库存 quantity、stock_value 和 revision，任何变化都拒绝；即使数量先减后增恢复原值，版本仍变化。须撤回/驳回、明确刷新快照并重新核对实盘与原因，不能覆盖最新库存。单据另有 version，编辑、提交、撤回、刷新、审核都要求 `expected_version`。

盘盈按现有正数库存价值 / 数量计价，不能因6位均价舍入为零就错误地认定无价格；无可用正价格须显式输入正单价（4 位）。盘亏按移动加权价值，全部盘亏吸收账面尾差；金额 2 位，库存均价 6 位。数量最多 3 位。极小数量乘正价格舍入到分可能为零金额，这属于明确价格下的舍入，不是无价格默认零。

仓库行是同仓库存写入的共同锁。审核状态、明细、库存调整、STOCKTAKE_GAIN / STOCKTAKE_LOSS 流水与审核记录在同一事务内写入；stocktake_item_id 唯一防止重复流水。多行任何一行快照冲突，前面调整全部回滚。盘点 project_id 为 NULL；只有显式公司库存授权可看公司盘点及库存，经理默认无此授权。

## 导入、导出与打印

仅支持供应商、材料、项目、仓库 CREATE_ONLY，不支持覆盖、期初库存、交易单导入。材料参考价不会生成库存。模板说明定义必填字段、单位（可使用企业自定义非空单位）、数量/价格/金额精度、日期与负责人登录名；负责人必须启用且为经理/负责人，经理只能指定本人。

只接受 xlsx，单次最多 2MB / 300 行、解压最多 20MB / 200 个 ZIP 项；拒绝公式、宏、外链及模板外列。预览逐行返回错误。正式导入重新解析原文件、核对预览 SHA256、重新检查权限、编号和关联信息，任一行失败整批回滚。数据库唯一键和导入文件摘要唯一键兜底并发重复。已有编号报错，不覆盖。

导出复用 `/records` 的模块权限、项目范围、搜索和关联筛选。最多 5000 条，超出明确要求缩小范围，不静默截断。申请/订单/入库/领料/盘点额外输出明细工作表。金额/数量为数值单元格，超过 15 位有效数字改用精确文本；日期为真实日期单元格，时间按上海时区。用户文本使用字符串单元格，包括以 `= + - @` 开头的文本，不作为公式执行。

供应商对账为当前累计余额，不编造期间期初期末；可按供应商、项目、订单或搜索筛选。打印由授权 API 生成转义 HTML，通过 iframe 预览；包含公司、单号、项目、明细、合计、制单人/时间及签字区，A4，不含侧栏、导航或业务按钮。数量权限的领料打印不含成本。打印不会执行付款；不连接银行。

详细入口、填写规则与模块覆盖见 [Excel 使用说明](EXCEL.md)。

## 本地复验

保留原实例 zqy-acceptance（18081 / 18082 / 13307）。本轮使用独立项目和卷：

```sh
HTTP_BIND_ADDRESS=127.0.0.1 UI_BIND_ADDRESS=127.0.0.1 \
UI_PORT=18091 API_PORT=18092 DB_PORT=13317 MYSQL_DATABASE=zhuqiyun_trial \
COMPOSE_PROJECT_NAME=zqy-trial ./scripts/start-compose.sh up -d --build
```

访问 http://127.0.0.1:18091 。默认演示账号见 README。首次构建需要下载镜像和开源依赖；构建后运行不依赖公网、域名或付费服务。

```sh
mvn -B -ntp -s deploy/maven-settings.xml -f backend/pom.xml test package
npm run build --prefix frontend
API_BASE=http://127.0.0.1:18092/api python3 scripts/test_http.py
API_BASE=http://127.0.0.1:18092/api python3 scripts/test_concurrency.py

API_BASE=http://127.0.0.1:18092/api python3 scripts/test_trial.py
```

这些脚本只新增可追踪 QA 单据，不清库。对本轮独立库以只读方式执行 `scripts/check_invariants.sql`，43 行 violations 都应为 0。重启后再次核对业务行数、迁移和附件，不把镜像构建成功当作业务验收。

## 明确边界

本轮不实现财税总账、银行或电子签章；不导入期初库存，不做自动付款。没有指定采购来源的历史领料不强行回填；无法解析的旧计划须人工确认。浏览器手机模拟可验证布局和操作，不等同于 iOS/Android 实机键盘、系统打印或物理打印机测试。Excel 导出上限和导入批量上限是本地小企业试用边界，不宣称大规模性能已压测。
