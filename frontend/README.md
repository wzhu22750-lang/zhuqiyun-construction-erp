# 筑企云前端

Vue 3 / TypeScript / Vite / Element Plus / Pinia / Axios / ECharts。

## 启动与构建

```sh
cd frontend
npm install
npm run dev
npm run build
```

开发地址为 http://localhost:5173；端口占用时以 Vite 输出为准。默认将 `/api` 转发到 `http://127.0.0.1:18080`。若主线程后端运行在 18081：

```sh
API_PROXY_TARGET=http://127.0.0.1:18081 npm run dev
```

可参考 `.env.example` 创建 `.env.local`。生产部署须配置 SPA 路由回退和 `/api` 反向代理，静态构建产物在 `dist/`。

## 实现范围

- 驾驶舱：8 个经营指标、ECharts 图表、待办及动态。
- 项目：列表、维护、详情及业务 Tabs。
- 采购：多行申请、提交、审批记录、供应商报价和逐材料比价、中选原因、下单。
- 订单：列表详情、部分验收入库、付款记录、取消未收货订单。
- 档案：供应商维护及详情（报价、订单、后端汇总指标）、材料和仓库维护。
- 库存与成本：库存流水、多行领料、项目成本及费用登记。
- 合同与财务：合同维护、附件上传下载、应付、付款登记和付款申请执行。
- 系统：账号维护、角色菜单及按钮权限、品牌、字典更新、审计记录。

所有业务数据通过 `docs/API-CONTRACT.md` 约定的真实接口读取或提交，无业务假数据。金额总额由后端提供，前端只格式化展示。权限同时控制菜单、路由和写入按钮，后端负责最终授权及业务校验。登录快捷选择只预填真实角色用户名；密码按后端当前配置输入。

## 验收交接

依赖安装及生产构建已执行。浏览器交互和真实后端业务闭环由主线程验收，本次交付不代表运行时验收已通过。

建议按以下顺序验收：登录与品牌 → 项目/供应商档案 → 采购申请提交和审批 → 至少两家逐材料报价、中选并下单 → 部分收货 → 库存领料与成本 → 应付付款/付款申请 → 合同附件 → 不同角色路由和按钮权限。

接口返回数组采用前端搜索与分页；字典提供更新、仓库提供新增与修改，按契约不增加未提供的删除接口。付款申请通过财务执行接口处理。

手机浏览器采用小于 768px 的响应式布局：抽屉导航、业务卡片、纵向材料录入及可滚动弹窗；桌面保留表格。具体访问方式和验收证据见 [手机适配说明](../docs/MOBILE.md)。
